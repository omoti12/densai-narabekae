# でんさい支払並べ替え

会計ソフトの「支払一覧表」を、でんさいの「取引先一覧」（利用者番号の昇順）と同じ順番に並べ替えるページです。

## 使い方

1. ページを開く
2. 支払一覧表のPDFをドラッグする（または「PDFを選ぶ」）
3. でんさいの順番で表示されます。黄色・赤の行は、右の欄で正しい取引先を選んでください
4. 「PDFで出力」を押すと、元の支払一覧表と同じ形式（左端に 1, 2, 3… の番号付き）のPDFが保存されます。「Excel用にコピー」「印刷」も使えます

読み込んだPDFはブラウザの中だけで処理され、どこにも送信・保存されません。

## 取引先が変わったとき

`torihikisaki.js` の一覧を、でんさいの取引先一覧と同じ順番に書き換えてください。
